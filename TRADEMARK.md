# Name use

"Lostname" names this project. VDHome stewards the name (not a registered trademark).

- You may use the name to refer to the project, and to say a product works with it or is built on it.
- A modified version must not be called Lostname or presented as an official release without a clear statement of what
  was changed.
- The mark (`brand/`) may be used, unmodified, to point to this project.
- Conformance claims, where the project defines a conformance set: "conforms to Lostname X.Y" only if every MUST of the
  claimed classes is met and the conformance set passes.

Questions: open a Discussion.
