# l*stname. brand

| Asset | File | Use |
|---|---|---|
| Wordmark | `final/wordmark.svg`, `final/wordmark-dark.svg` | headers, docs, the social card |
| Mark `*.` | `final/mark.svg`, `final/mark-dark.svg` | next to text, small inline use |
| Badge | `final/badge.svg` (also `final/favicon.svg`) | avatars, favicons, app icons; never inverted |
| Icons | `final/favicon.ico`, `final/apple-touch-icon.png`, `final/avatar-500.png` | browsers, devices, the GitHub organisation |
| Social card | `final/social.png` | repository social preview (1280x640) |

**Rules:**
- **Colour:** DNS syntax in gold, the name in ink. The asterisk (the wildcard) and the period (the root) are gold; the letters are ink, or paper on dark grounds.
- **Name:** `lostname` everywhere technical (binary, package, organisation, domains). `l*stname.` is the wordmark only.
- **Typeface:** JetBrains Mono (SIL Open Font License 1.1, `Fonts/OFL.txt`).
- **Don'ts:**
  - Don't redraw the asterisk with the font's own glyph.
  - Don't recolour the mark.
  - Don't place it on orange or blue grounds.
